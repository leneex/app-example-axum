# Axum

Пример приложения Axum, которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `5000` |
| Путь проверки состояния | `/` |

Приложение слушает порт из переменной окружения `PORT` — её передаёт платформа, — а без неё `5000`.

## <a name="dev"></a>Локальный запуск проекта
```bash
# установка зависимостей
cargo fetch

# запуск в дев режиме
cargo run

# сборка для продакшн
cargo run --release
```
